# PipeGen Export Archive
## Project: Workplace Safety Sentinel (Track A)
**CraftifAI PipeGen Version:** v0.5.1  
**Target Environment:** x86_64 Linux (NVIDIA RTX 40-series / Jetson Orin with JetPack 6)  
**DeepStream Version:** 7.0 / 6.4 Compatible  
**TensorRT Version:** 10.0+  

---

### Five-Stage Workflow Execution Record

1. **Stage 1: Requirement Specification (`requirement.yaml`)**
   - Natural language and structured prompt defining workplace person detection, restricted dangerous zones, real-time latency target ($\le 30\text{ ms}$), and JSONL actionable logging.
   
2. **Stage 2: Pipeline IR Graph (`pipeline_ir.json`)**
   - Declarative computational graph generated by PipeGen:
     - `filesrc` (Local MP4 video) $\to$ `qtdemux` $\to$ `h264parse` $\to$ `nvv4l2decoder`
     - `nvstreammux` (Batching: 1, 1920x1080)
     - `nvinfer` (TensorRT FP16 person detection engine)
     - `nvtracker` (NvSORT / NvDCF tracking module)
     - `safety_sentinel_probe` (Python pad probe / metadata extractor)
     - `nvdsosd` $\to$ `nvoverlaysink` / `filesink`

3. **Stage 3: Model Selection (`model_config.json`)**
   - Selected person-detection model from PipeGen Deep Search catalog.
   - Backbone: CSPDarknet / YOLOv8-person detector optimized for industrial personnel.
   - Input resolution: $640 \times 640 \times 3$.

4. **Stage 4: TensorRT Compilation (`speed_report.json`)**
   - Compiled through PipeGen TensorRT Compiler using **FP16** precision.
   - Measured engine latency: **9.8 ms** (vs 42.1 ms PyTorch baseline).
   - Speedup: **4.29x**.

5. **Stage 5: Run / Deployment**
   - Executed live on local video source.
   - Metadata dispatched to `safety_events` logic for zone intrusion analysis.
